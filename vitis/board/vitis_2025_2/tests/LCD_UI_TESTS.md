# LCD 界面回归与预览

执行：

```powershell
python vitis_2025_2/tests/run_lcd_ui_tests.py
```

需要 64 位 GCC / Clang 和 Pillow。脚本会优先搜索 PATH，也支持 `--cc C:/mingw64/bin/gcc.exe`。

测试编译实际 `mess.c`、实际 `mess.h` 和实际 `main.c` 主循环；LCD 绘制函数从实际 `lcd.c` 提取，保留原实现和原 `font.h` 字库。`LCD_DrawPoint` 额外记录越界调用次数，不改变绘图行为。替换的只有 BSP、摄像头设备访问、定时器、推理输出和 FatFs 适配层。测试文件均位于本目录的 `.build/lcd_ui`，不会操作 SD 卡和开发板。

覆盖内容：

- 三个按钮的整个命中区域、外侧一像素、半开边界、空触摸、非法网格，测试 LCD 翻转开和关；检查命中函数不消费触摸事件。
- 六类最大值选择、全负/最小值/并列分数、计时、无效输入；检查推理函数不绘制 LCD。
- 保存 BMP 的文件头、负高度、24 位 BGR 像素、完整文件长度；Pillow 再独立解码并比较全部像素。
- 空输入、SD 初始化失败、建目录失败、查询文件失败、写入失败；失败不增加保存计数，跳过已有文件和残留文件。
- 新进程模拟重启；保存计数重新从 1 开始，原有文件保持不变；所有 99,999 个文件名被占用时停止且不覆盖。
- 实际主循环中的长按仅执行一次，松开后再按生效；相机离线、模型不可用、检测失败、补光 IIC 失败；模型不可用时保存仍能执行。
- 实际渲染七种页面：等待、检测结果、检测中、保存中、保存失败、相机离线、模型不可用；检查界面更新不改写预览区域、最大保存数量和所有类别文本不越界。
- 两种翻转配置生成的实际像素，在反向旋转后逐字节完全相同。

`lcd_previews/*.png` 来自真实 C 绘图代码和字库。左侧叶片是测试程序生成的**模拟摄像头图像**，不代表上板截图或真实模型输出。`states.png` 是带此说明的状态总览；`verification.json` 记录编译器、执行结果和实际源文件 SHA-256。

测试不验证物理 LCD/触摸屏、真实 SD 卡介质、DMA 帧一致性或模型识别准确率。这些仍需上板检查。
