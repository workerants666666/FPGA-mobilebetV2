## 资格和设计范围

- 初级组参赛资格为大学一年级至三年级在读本科生。指南规定队伍混合年级或学历时按其中最高者归入高级组，并通过学生证与学历审核；本队需要核对全部队员资格。
- 初级组器件范围：AMD 7 Series FPGA、Zynq-7000 SoC、UltraScale、UltraScale+。提交物须声明实际器件型号，并在实际可获取的板卡上完成验证。Zynq-7000 类板卡在器件范围内，具体 AC820 板卡、芯片后缀和电气版本仍应以实物和工程约束核对。
- 选题应用方向不限；RTL、Vitis HLS、PS 软件等实现方式及组合不受限定，最终须是一件完整、可复现、可演示的 FPGA 作品。
- 初级组侧重逻辑设计、状态机、时序约束、接口协议等基本 FPGA 能力。高级组和初级组独立排名与评奖，但任务、提交内容、评测指标和权重相同。
- **PYNQ 是推荐方向，不是强制平台，也不是必须购买 PYNQ-Z2。** 指南推荐 PS 侧 Python/Jupyter 组织算法和数据流，PL 侧 HLS/RTL 核心封装为 Overlay。PYNQ 框架迁移仍需要说明实际 PL 核心、接口及验证工作。

依据：PDF 物理 22-23、26 页。

## 工具和工程要求

| 项目 | 指南要求 | 对本工程的落实方式 |

| 板级实测 | 作品须在板上跑通并提供实测输出 | 软件离线测试只能标记为软件验证，待实际板卡记录型号、镜像、核频率、结果和错误日志 |
| 性能优化 | 性能可测量，给出基线对照，兼顾资源代价 | 固定输入、预处理、精度、统计方式；区分加速核耗时与端到端耗时，并附资源和时序报告 |
| 复现 | 他人可从零复现，提供构建脚本 | 补齐实际使用的 RTL/HLS/IP、Vivado BD/XDC/Tcl、模型权重与许可、依赖版本和命令；脚本不能在缺源时声称构建成功 |
| 大模型协作 | 允许公开大模型、微调本地模型和智能体；须提交提示词、回答、自我纠错轨迹 | 保存实际聊天导出和修改/验证记录。摘要不能冒充原始逐轮记录 |
| Skill | 协作经验须提炼为技能包并随作品提交 | `skill/README.md` 逐项说明场景、用法、失效条件、已验证效果及失败/观察来源 |

### 开源措辞和授权边界

指南第 3.3.3.3 原文为“所有提交作品强烈要求在 GitHub 或 Gitee 上开源”，协议须允许再分发，推荐 MIT 或 Apache-2.0。应按重要提交要求准备，但不能把“强烈要求”改写成已获得用户发布授权。发布前须由队伍确定自有代码、供应商资料、第三方 IP、训练数据和权重各自的再分发权限，并保留相应许可证；本地移植工作不需要先发布仓库。

## 提交物清单

### 工程包

- 实际采用的完整源码和工程文件，包括 RTL/HLS/PS 软件。
- 仿真或验证结果，以及功能正确性的确认方法。
- 综合与实现报告，包括资源占用、时钟频率、关键性能指标。
- 上板工程、运行脚本、实测输出以及与参考结果的比对数据。
- 可复现的构建脚本。

### 技能包

置于 `skill/`，包含 `README.md`。可使用经过验证的提示词工作流、案例/工程模板、校验脚本、踩坑清单等形式。每项应写明适用场景、使用方法、失效条件、已验证效果，以及从哪些失败或观察中提炼而来。评判重点是陌生队伍能否直接复用。

**通用 PYNQ Skill 另行加分**：须与本队题目解耦，换题目、换板卡仍可用。指南举例包括 Overlay 加载和寄存器映射、DMA/缓存一致性、接口契约生成代码、黄金参考和性能资源报告工具。指南**未给额外加分的具体分值、上限或计算公式**，不能承诺加几分，也不能仅凭编写文档宣称已经跨板实证。

### 设计报告

- 选题背景、创新点、实际问题和已有相关工作。
- 原理与功能框图。
- 软硬件划分依据与接口设计。
- 优化过程及优化前后性能/资源表。
- 大模型提示词、回答、自我纠错轨迹；如用智能体，说明工作流。
- Skill 的失败/观察来源、有效性验证和适用边界。
- 他人从零执行的完整复现步骤。

### 路径命名和推荐结构

指南要求仓库目录和文件名采用英文、数字、下划线或连字符，不得有中文、空格或特殊字符。指南同时明确给出 `README.md` 等含大写字母和扩展名点号的标准文件名示例，按其示例保留这些约定文件名；其他新增路径使用小写 ASCII。供应商原始包及本地中文指南保留作本地证据，不应直接作为最终整理仓库的路径结构。

推荐 `src/`、`sim/`、`build/`、`board/`、`data/`、`skill/`、`report/` 和根 `README.md`。这套目录结构是推荐而非强制，采用其他结构时在 README 中给对照。

依据：PDF 物理 24-25 页。
