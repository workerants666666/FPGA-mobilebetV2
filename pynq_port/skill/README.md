## 从本工程提炼的经验

1. 工程名不足以确定任务：活动标签是水稻病害六类，应检查当前生效的源码和权重，不能依据 Trash 文件夹名替换任务。
2. XSA 是重要恢复证据，但不能代替 Vivado BD/RTL/HLS/IP 源码；可恢复运行包与可从零重建的工程应分别验收。
3. bit/HWH 同名只是加载条件之一，还要同次构建、同器件、同地址映射；不同 I/O 电压版本不能混用。
4. 裸机固定 DDR 地址不能照搬到 Linux；缓冲须按 `allocate` 获得的设备地址编程，依据缓存方向同步。
5. 等待超时不等于 PL 已停止访存。错误路径也须保留缓冲，待停止/复位并确认无访存后才能释放。
6. HWH 能描述 PL，不会自动把启动时禁用的 PS I2C 变成 Linux 可用的 `/dev/i2c-*`；还要核对镜像、设备树、引脚和总线所属控制器。

这些是本次文件审计与文档对照后形成的规则。当前未完成真实板卡验证，也未完成换题目/换板卡验证。请使用实际结果填写下表后再声称“已验证通用性”；是否获得额外分数由赛事评审决定。
